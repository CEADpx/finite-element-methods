# Advanced Finite Element Methods

This repository contains the open book and course materials associated with
*Advanced Finite Element Methods*, including material for Fall 2026 ME/BME 736.

- `book/` contains the Quarto book.
- `notebooks/` contains computational notebooks.
- `examples/` contains standalone FEniCSx examples.
- `assignments/` contains public assignment statements and starter files.
- `data/` contains datasets used in examples or assignments.
- `src/fem_utils/` contains reusable Python utilities.
- `course/` contains course-specific documents such as the syllabus.
